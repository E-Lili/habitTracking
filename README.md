# Трекер привычек
Веб-приложение для формирования и отслеживания полезных привычек. Позволяет управлять ежедневными задачами и визуально оценивать свой прогресс. 
## Функционал
### Страница задач (главная)
- **Добавление задачи** — создание новой привычки с названием
- **Отметка выполнения** — клик по чекбоксу фиксирует выполнение задачи на текущий день
- **Удаление** — безвозвратное удаление привычки из списка
- **Общая статистика** — сколько задач выполнено из общего количества
- **Сохранение данных** — все изменения автоматически сохраняются в localStorage

### Страница прогресса
- **Общая статистика** — сколько задач выполнено из общего количества
- **Список привычек с прогрессом** — для каждой привычки отображается процент выполнения
- **Динамика** — видно, какие привычки выполняются лучше всего
- **Текущий страйк** - сколько дней в неделю выполнены все привычки
- **Самый длинный страйк** - показывает рекорд по непрерывному выполнению всех привычек в один день

### Технологии
- HTML5 — семантическая разметка
- CSS3 — адаптивная вёрстка (Flexbox)
- JavaScript — вся логика приложения
- LocalStorage — хранение данных пользователя
